# 03：正式 Gateway 入口在缺少或不合格秘密時安全停止

**What to build:** `python -m bot` 的正式入口在啟動前呼叫秘密讀取（01）與權限判定（02）。缺少或不合格時，程序以明確但不含秘密的訊息結束，不嘗試登入 Discord，也不建立資料庫連線。

**Blocked by:** 01、02

**Status:** ready-for-agent

**File owner:** `bot/__main__.py`、`tests/test_entry_secret_refusal.py`（新）

**TDD 驗證：**
- 紅：缺少 Discord Token 秘密時，入口拒絕啟動，且未呼叫登入。
- 紅：缺少資料庫密碼秘密時，入口拒絕啟動，且未建立資料庫連線。
- 紅：秘密權限判定為拒絕時，入口拒絕啟動。
- 紅：拒絕時的標準輸出與錯誤輸出不含任何秘密假值。
- 紅：拒絕時退出碼不為 0。
- 綠後重構：入口只保留「讀取、判定、組裝、啟動」的順序，不把判斷散落。

**Acceptance criteria:**
- [ ] 任一必要秘密不合格，入口在登入前停止。
- [ ] 停止訊息只列出設定名稱與原因代碼，不含值或完整路徑以外的敏感資訊。
- [ ] 測試以替身取代登入與資料庫連線，證明未被呼叫。
- [ ] 不修改既有 Owner 指令的行為（由 04 處理）。
- [ ] 離線測試以 Python 3.12 執行通過，並列出通過、失敗、略過數量。

**Out of scope:** Owner 接線（04）；容器層級的驗證（10）。

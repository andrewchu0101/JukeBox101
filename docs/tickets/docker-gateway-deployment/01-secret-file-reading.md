# 01：明確支援從秘密檔案讀取資料庫密碼與 Discord Token

**What to build:** 程式在啟動時能從指定的秘密檔案讀取資料庫密碼與 Discord Token。來源可以是環境變數或秘密檔案，但同一個設定不能兩者都提供。缺少、空白或無法讀取時，啟動即拒絕，錯誤訊息只列設定名稱，不輸出任何值。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**File owner:** `bot/config.py`、`tests/test_secret_file_reading.py`（新）

**TDD 驗證（紅→綠→重構，先寫測試）：**
- 紅：只提供秘密檔案路徑時，讀到的值與檔案內容一致（去除首尾換行）。
- 紅：同時提供環境變數與秘密檔案路徑時，拒絕啟動。
- 紅：秘密檔案不存在、為空、只有空白時，拒絕啟動。
- 紅：拒絕訊息與例外字串不包含秘密值（以含特殊字元的假值驗證）。
- 紅：未提供任何來源時，拒絕啟動，且不使用預設值。
- 綠後重構：兩種來源共用同一個解析入口，不複製判斷。

**Acceptance criteria:**
- [ ] 資料庫密碼與 Discord Token 皆支援秘密檔案來源。
- [ ] 兩種來源同時提供時拒絕（不靜默擇一）。
- [ ] 缺少、空白、無法讀取時拒絕，不以空值啟動。
- [ ] 錯誤訊息與日誌不含秘密值。
- [ ] 不依賴 `_FILE` 環境變數自動生效；檔案路徑本身由環境變數指定，但路徑不是秘密。
- [ ] 離線測試以 Python 3.12 執行通過，並明確列出通過、失敗、略過數量。
- [ ] 不連線 Discord 或 MySQL。

**Out of scope:** 權限判定（見 02）；入口接線（見 03）。

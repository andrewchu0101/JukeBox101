## 換電腦取得程式

私人 repository 的分支為 `feature/owner-review-offline-checkpoint`。使用有存取權限的 GitHub 帳號 clone，切換該分支，記錄 `git rev-parse HEAD`。依 `docs/deploy/partner-deployment.md` 建置與部署。Git 不包含秘密、資料庫資料、候選映像匯出檔或私人 PDF。

既有第五版部署包是另外交付的離線產物，不會因 push 自動出現在 GitHub。其去識別化參考 PDF 位於 `docs/reference/Discord-bot-policy-inquiry-reply-deidentified-2026-10-30.pdf`（部署包內路徑）；映像、第三方授權全文與校驗碼須隨部署包另外傳遞。後續文件提交不代表舊包已自動更新。

## 資料庫不在新電腦上

`compose.yaml` 只有 Bot，沒有 MySQL 服務，也不會自動建立雲端資料庫。新部署主機不需要安裝本機 MySQL；它需要能連線到已準備好的外部 MySQL。

若已有正式資料庫，沿用它，不因換電腦重新初始化。若尚無資料庫，Owner 與夥伴須先準備外部 MySQL、schema、必要 migration、最小權限應用帳號及備份，再填入 `.env` 的 DB_HOST / DB_PORT / DB_NAME / DB_USER。db_password.txt 是該應用帳號的密碼，不是雲端帳號密碼。

現有連線程式沒有明確配置 MySQL TLS 憑證及驗證參數，不能假定任一強制 TLS 的雲端服務可直接使用。部署前確認相容的安全連線方式；優先使用部署主機可達的私有網路，不將 MySQL 3306 開放給整個網際網路。不在此指定雲端供應商或建立付費資源。

資料庫 migration 與投稿就緒檢查依 `docs/deploy/owner-secrets.md` 及 `docs/owner-migration-verification.md` 執行。不得偽造 jb2_control 就緒紀錄；Bot 已登入不代表投稿已可受理。

# 下一個 MVP：自動審核與 Nickel 發獎

日期：2026-10-31（Asia/Taipei）。狀態：產品方向已確認，尚未實作／部署／啟用。

## Owner 已確認的方向

- 不再要求正常投稿逐筆到 VPS 補時長及人工核准。
- 自動判定採「YouTube 官方 API＋Owner 認可頻道，其餘待審」。此為產品採信規則，不表示頻道內每部影片必然是完整歌曲。
- 審核通過且符合既有首次版本獎勵資格時自動發放 1 Nickel；正常重送／並行／重啟不重複發放。非首次投稿不可因再次核准而領獎。
- 例外案件的人工補證據與確認應在 Discord 完成，不再要求每案操作 VPS。
- 既有同錄音 MV／Audio 共用版本獎勵、不同錄音版本與前序候選保護仍適用。本次沒有授權改為每 Video ID 各發一次。

## 給 Claude 的實作任務

先閱讀 CLAUDE.md、CODING_STANDARD.md、此規格、youtube-policy-confirmation.md，以及現有 eligibility、review、version_identity、reward_candidates、submission_repository、reward_settlement。重用既有交易與證據模型，不另建平行帳本。

1. **中繼資料入口**：用官方 Data API v3 取得所需時長／channel ID 等最少欄位；將 ISO 8601 時長正確轉為既有證據型別，禁止四捨五入、用標題猜時長、爬網頁或下載音訊。API 呼叫不得持有業務資料庫鎖；設 timeout、配額／失敗處理、可恢復重試及來源／取得時間。資料保存與更新依官方當前規範設計，不能把既有有範圍 Google 回覆解讀成全政策豁免。
2. **自動歌曲審核**：頻道採穩定 channel ID allowlist，不採顯示名稱；名單與採信規則版本可稽核。時長 60～720 秒含邊界，證據完整且符合歌曲／完整性規則才自動核准；私人、刪除、直播、premiere、不可判定、剪輯／非歌曲或衝突需有明確結果。不把 API 失敗變成永久拒絕，不偽造 Owner 手動判定紀錄。
3. **版本身分**：官方 API 中繼資料或頻道白名單不能單獨證明 MV／Audio 是同錄音。先核對現有 mapping／可信版本證據；已知映射可自動沿用，未知身分待審。不得用標題、不同 Video ID 或隨機 version ID 自動證明不同版本。若要擴大未知版本的自動化，先提出證據來源與可實作規則讓 Owner 決定。
4. **Discord 例外入口**：新增 Owner 補時長／歌曲與版本證據的預覽→確認操作，沿用 actor／guild guard、expected revision、短效一次性確認及持久稽核。保留人工拒絕、衝突與重審規則。每個命令需附實際意義，不讓管理者填內部狀態或 READY。
5. **自動結算**：審核／身分證據更新後，以既有受理順序與鎖內重算決策，資格完成才呼叫既有原子 reward settlement。唯一版本 claim、ledger +1、餘額、候選與結算回執必須一致；失敗回滾，COMMIT 未知用原 key 查回執。前序解除時需能喚醒受阻候選，不能只處理當前事件，也不能跳過較早未知候選。
6. **開關與健康契約**：目前 readiness／healthcheck 要求 settlement_enabled=false；若新 MVP 啟用發獎，必須一起更新其明確 feature policy 與測試，不能只開資料庫旗標導致健康失敗。API／審核／結算的設定應 fail closed，且可停用。exchange、claim、daily、補償維持原關閉狀態。
7. **使用者回覆**：分清楚已受理待驗證、已核准待版本／前序、已發放 +1、重複不發及結果未知。只有交易確認後才顯示已發放；/balance、/history 必須呈現一致結果。

## 驗收

- 正常認可來源：自動補時長、資格審核；已確認版本的首次合格投稿正好 +1，ledger 與 /balance 一致，不需逐案 VPS 操作。
- 例外來源可從 Discord 補證據；完成資格後自動結算，不能要求手動操作 ledger。
- 重送、同版本不同影片、跨使用者並行、前序等待／解除、API 限流／失敗、舊證據、Owner 重複確認、重啟與 COMMIT 未知不得重發。
- 使用可丟棄 PostgreSQL 17 與 18 驗證真實交易，覆蓋部署使用的 Session Pooler 相容性，不把 mock 當正式網路驗收。
- API 外部呼叫與真實 Token 分開驗收；測試不連正式資料庫、不修改既有投稿或餘額。
- 先 PR／CI，通過後另行安排部署與功能啟用；此文件不代表正式結算開關已打開。

## 實作所需輸入與未決事項

- Owner 認可的實際 channel ID 清單尚未提供；不可自行挑選頻道或只憑網址標題納入。
- 官方 Data API 的 Google Cloud 專案／憑證與配額配置待確認，秘密不進 Git 或聊天。
- 認可頻道內的完整歌曲辨識條件、未知錄音版本的自動證據規則待定；這兩項不能默默當作「全都通過」。
- 人工已核准但版本未知的首筆案件不因本規格自動補發；待證據齊全後走相同冪等結算流程。
